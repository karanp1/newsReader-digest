Open Claw NewsletterPrivacy Bugs Caught Before Release

02 Nov 2026

  • Meta deployed Catching JiTTests, a system using large language models to generate tests that catch bugs in code changes before they land in production.
  • The approach generates executable tests designed to fail, surfacing bugs that traditional LLM or agent-based code reviews might miss.
  • Two workflows run in tandem: an intent-aware workflow that infers a change's risks, and a dodgy diff workflow that treats each change as a mutant.
  • False positives are filtered by combining a rule-based assessor called RubFake with an LLM-as-Judge ensemble that aggregates judgments from several state-of-the-art LLMs.
